# HTML Websites
[LIVE SITE](https://cameroncodesstuff.github.io/FREE-single-file-HTML/)

A collection of **11 fun, weird, interactive HTML websites** built with plain HTML, CSS, and JavaScript.

No frameworks.
No complicated setup.
No dependencies.

Just open an `.html` file in your browser and you're good to go or open with [link](https://cameroncodesstuff.github.io/FREE-single-file-HTML/).

## Publishing Your Website

Want to put one of these websites online so other people can visit it?

Use this publishing tutorial:

### [GitHub Website Publishing Tutorial](https://cameroncodesstuff.github.io/tutorial/)

The tutorial explains how to publish websites using GitHub.

Once published, you'll have a shareable website URL that you can send to your friends, put in your bio, or show off like you just invented the internet.

## Technologies

These projects are made using:

* **HTML** — Structure
* **CSS** — Styling and animations
* **JavaScript** — Interactivity
* **Browser APIs** — Features such as `localStorage`

There are no external libraries required.
