One-time setup: multiplayer needs a free Firebase Realtime Database to relay positions between players. Create one (2 minutes), then paste its config below.
1. Go to console.firebase.google.com, sign in, click Add project
2. In the left menu: Build → Realtime Database → Create Database → start in test mode
3. Click the ⚙️ gear → Project settings → scroll to Your apps → click </> (web) → register an app
4. Copy the whole firebaseConfig code block it shows you and paste it below
